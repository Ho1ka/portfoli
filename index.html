Java Core & ООП

Основний стек розробки

• ООП: Розуміння та застосування інкапсуляції, наслідування, поліморфізму та абстракції на практиці.

• Collections Framework: Використання ArrayList, LinkedList, HashMap, HashSet залежно від структури даних.

• Exception Handling: Обробка стандартних винятків, створення власних класів винятків через try-catch.

• I/O Streams: Зчитування та збереження даних у текстові файли для збереження стану програми.

C++

Базовий рівень та алгоритми

• Вказівники та посилання: Розуміння адресної арифметики та передачі параметрів за посиланням.

• Управління пам'яттю: Динамічне виділення пам'яті (new / delete) та запобігання витокам пам'яті.

• Базові структури: Робота з одновимірними та двовимірними масивами, структурованими даними (struct).

HTML5 & CSS3

Верстка та веб-основи

• Семантичний HTML: Побудова зрозумілої та правильної структури веб-сторінки.

• Адаптивність: Використання Flexbox, CSS Grid та фреймворків (Tailwind CSS) для гарного вигляду на телефонах і ПК.

Git & Інструменти

Системи контролю версій

• Команди Git: init, clone, add, commit, push, pull, status.

• Платформи: Робота з віддаленими репозиторіями на GitHub.

• Середовища розробки: Налаштування та робота в IntelliJ IDEA, VS Code.

Консольна система обліку (Java)

Курсовий або навчальний проєкт, розроблений під час навчання в коледжі. Програма дозволяє додавати, редагувати, видаляти та шукати записи через текстове меню в консолі. Реалізовано збереження даних у файл для повторного завантаження при запуску.

Алгоритмічна програма (C++)

Практична робота з реалізації ключових алгоритмів обробки масивів та структур даних. Програма демонструє роботу з пам'яттю через вказівники та динамічне виділення ресурсів.
